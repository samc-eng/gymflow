# GymFlow

Mobile-first PWA for tracking gym sessions, built for students at Télécom SudParis.

## Features

- Session tracking (sets, reps, loads)
- Machine database with real-load calculation via pulley factor (×1, ×2, ×4)
- Crowd-sourced machine catalogue
- Pre-built and custom training programs (PPL, Full Body, Push/Pull…)
- Pre / during (RPE) / post-session feedback
- ML-based load recommendations and plateau detection *(planned)*

## Stack

Next.js (App Router, TypeScript) · PostgreSQL + Prisma · Auth.js · FastAPI + scikit-learn · Cloudinary · Vercel + Railway
